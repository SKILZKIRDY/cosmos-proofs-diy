# 🌍 Cosmos Proofs DIY

Run experiments. Measure visibility. Share real-world observations.

---

## 🚀 Overview

Cosmos Proofs DIY is a community-driven platform for running real-world experiments, calculating visibility, and sharing observed results.

It combines interactive tools, user-generated submissions, and experiment tracking into one streamlined experience.

---

## 🧪 Core Features

### 🔢 Observation Calculator
A unified visibility calculator that allows users to input:

- Observer height  
- Target height  
- Distance  

And instantly calculate:
- Horizon distance  
- Hidden height  
- Viewing angle  

---

### 📸 Community Submissions
Users can:
- Upload experiment photos  
- Add notes and observations  
- Share real-world results  

Submissions are tied to experiments and visible to the community.

---

### 👤 User Profiles
Each user has a profile with:
- Contributions  
- Experiment activity  
- Saved data  

---

### ⭐ Bookmarks & Notes
- Save experiments  
- Add personal notes  
- Track progress  

---

## 🧠 Purpose

This platform encourages:

- Hands-on experimentation  
- Real-world observation  
- Measurement and documentation  
- Community participation  

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)  
- **Backend:** Supabase (Auth, Database, Storage)
